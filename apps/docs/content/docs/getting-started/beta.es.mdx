Revisa esta página antes de instalar nada. Resume qué admite la beta para cada rol y qué equipo, cuenta y
fondos necesita cada uno.

## Alcance de la beta [#qué-puedes-hacer-hoy]

| Tarea                           | Durante la beta                                                                                                 |
| ------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| Conversar con modelos           | App de escritorio, ofertas gratuitas. No necesitas billetera ni fondos.                                         |
| Conectar herramientas de código | Una API key de la app de escritorio, con límite de gasto. Ofertas gratuitas y con precio.                       |
| Ejecutar un vendedor            | Vendedor Docker, o vendedor nativo sin Docker. El instalador sirve Qwen3 0.6B en Ollama, sin razonamiento.      |
| Ofrecer inferencia gratuita     | Límites diarios de tokens, en total y por comprador.                                                            |
| Cobrar por la inferencia        | Ofertas con precio por solicitud en devnet, pagadas en USDC de devnet. Consulta [Cobrar](/es/sellers/get-paid). |
| Registrarte y publicar          | Necesitas un código de invitación. Registrarte en el registro de agentes 8004 cuesta un poco de SOL de devnet.  |
| Usar otros motores y modelos    | Configuración avanzada. Que el archivo pase la validación no demuestra que el modelo funcione bien.             |
| Mainnet                         | Se rechaza. `network = "mainnet"` en `config.toml` falla la validación con `MAINNET_UNSUPPORTED`.               |

El SOL y el USDC de devnet no tienen valor de mercado. La electricidad, el alojamiento e internet sí
cuestan, y un motor remoto puede cobrarte aunque la oferta sea gratuita.

## Usa Gyblos como comprador [#requisitos-del-comprador]

Para la [app de escritorio](/es/buyers/desktop-app):

- macOS en Apple Silicon (M1 o posterior), Windows 10 u 11 (x64) o Linux (x64). No hay versión para Mac
  con Intel.
- Acceso a internet hacia el índice de descubrimiento, Solana devnet y los relays de Gyblos.
- Ninguna invitación: la app no necesita código de invitación.

Para [conectar tus herramientas de código](/es/buyers/use-from-code) no necesitas nada más: la app te da la
API key y la Base URL.

## Ejecuta un vendedor [#antes-de-instalar]

- Una invitación con un **código de invitación** de un solo uso que empieza con `gyb_`. No necesitas token
  de relay. Si no la tienes, pídela en el [Telegram de Gyblos](https://t.me/gyblos).
- Un equipo que permanezca encendido, con al menos **4 GB de memoria** y varios GB de disco libre.
- Acceso saliente a internet. El vendedor no abre ningún puerto de escucha; se conecta hacia los relays.
- Uno de estos tipos de instalación. El instalador usa Docker si tu cuenta puede ejecutarlo y, si no, el
  vendedor nativo:

| Tipo de instalación | Plataformas                                        | Qué pones tú                                                         |
| ------------------- | -------------------------------------------------- | -------------------------------------------------------------------- |
| Vendedor Docker     | Linux (x86-64 o ARM64) o macOS                     | Docker Engine con Compose **v2.17 o posterior**, o Docker Desktop    |
| Vendedor nativo     | macOS en Apple Silicon, Linux (x64 o arm64, glibc) | Tu propio [Ollama](https://ollama.com/download)                      |
| Vendedor nativo     | Windows 10 u 11 (x64), con `install.ps1`           | Tu propio [Ollama para Windows](https://ollama.com/download/windows) |

Los Mac con Intel y Linux con musl (Alpine) necesitan Docker. En un Mac con Apple Silicon el vendedor
nativo es más rápido, porque Docker no puede usar la GPU. Consulta la guía [Instala un vendedor](/es/sellers/beta-guide)
para cada camino.

Con un motor local, el vendedor anuncia su oferta solo mientras quede libre al menos **1,5 GiB** de memoria
además del propio vendedor. Por debajo de eso sigue en marcha, pero sin publicarse. El modelo también
necesita memoria.

En Linux, pertenecer al grupo `docker` da a una cuenta control de nivel root sobre el equipo. Cuando el
instalador no puede usar Docker, te sugiere añadir tu cuenta a ese grupo. Hazlo solo si esa cuenta puede
tener ese poder; si no, deja que el instalador configure el vendedor nativo.

También necesitas un poco de **SOL de devnet** del [faucet de devnet](https://faucet.solana.com): unos
0,02 SOL en la dirección del dueño (owner) para registrarte, y unos 0,05 SOL en el pagador de comisiones (fee payer) si cobras por la
inferencia. El instalador muestra ambas direcciones. Nunca uses fondos ni claves de mainnet.

## Datos que salen de tu equipo [#datos-que-salen-de-tu-equipo]

Las versiones publicadas del vendedor y de la app de escritorio suben recibos firmados y sin contenido al
recolector de métricas de Gyblos, `collector.gyblos.com`. Los recibos no se pueden desactivar. También
suben observaciones de telemetría sin contenido, que `GYBLOS_OBSERVATIONS=off` desactiva. Ninguno incluye
mensajes ni respuestas. Consulta [Datos y privacidad](/es/reference/data-and-privacy) para la lista
completa.
