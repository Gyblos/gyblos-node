Check this page before you install anything. It lists what the beta supports for each role and the
machine, account and funds each role needs.

## Beta scope [#what-you-can-do-today]

| Task                         | During the beta                                                                                           |
| ---------------------------- | --------------------------------------------------------------------------------------------------------- |
| Chat with models             | Desktop app, free offers. No wallet or funds needed.                                                      |
| Call models from code        | Local buyer from the source repository, free offers. Paying a seller from code is a pilot.                |
| Run a seller                 | Docker seller, or native seller without Docker. The installer serves Qwen3 0.6B on Ollama, reasoning off. |
| Offer free inference         | Daily total and per-buyer token caps.                                                                     |
| Charge for inference         | Priced per-request offers on devnet, paid in devnet USDC. See [Get paid](/en/sellers/get-paid).           |
| Register and publish         | Needs an invite code. Registering in the 8004 agent registry costs a little devnet SOL.                   |
| Use other engines and models | Advanced configuration. A file that passes validation does not prove the model serves well.               |
| Mainnet                      | Refused. `network = "mainnet"` in `config.toml` fails validation with `MAINNET_UNSUPPORTED`.              |

Devnet SOL and devnet USDC have no market value. Your electricity, hosting and internet still cost
money, and a remote engine may charge you even for a free offer.

## Use Gyblos as a buyer [#buyer-requirements]

For the [desktop app](/en/buyers/desktop-app):

- macOS on Apple Silicon (M1 or newer), Windows 10 or 11 (x64), or Linux (x64). There is no build for
  Intel Macs.
- Internet access to the discovery index, Solana devnet and the Gyblos relays.
- No invitation: the app needs no invite code.

To [call models from your code](/en/buyers/use-from-code) you also need Git, Node.js 24.22.1 or later
and pnpm (`corepack enable` provides it). The local buyer runs from the source repository.

## Run a seller [#before-you-install]

- An invitation with a one-use **invite code** that starts with `gyb_`. You do not need a relay token. If you
  don't have one, ask for it in the [Gyblos Telegram](https://t.me/gyblos).
- A machine that stays on, with at least **4 GB of memory** and a few GB of free disk.
- Outbound internet access. The seller opens no listening port; it connects out to the relays.
- One of these install types. The installer uses Docker when your account can run it, and the native
  seller otherwise:

| Install type  | Platforms                                           | You provide                                                        |
| ------------- | --------------------------------------------------- | ------------------------------------------------------------------ |
| Docker seller | Linux (x86-64 or ARM64) or macOS                    | Docker Engine with Compose **v2.17 or later**, or Docker Desktop   |
| Native seller | macOS on Apple Silicon, Linux (x64 or arm64, glibc) | Your own [Ollama](https://ollama.com/download)                     |
| Native seller | Windows 10 or 11 (x64), with `install.ps1`          | Your own [Ollama for Windows](https://ollama.com/download/windows) |

Intel Macs and Linux with musl (Alpine) need Docker. On a Mac with Apple Silicon the native seller is
faster, because Docker cannot use the GPU. See [Install a seller](/en/sellers/beta-guide) for each path.

With a local engine, the seller advertises its offer only while at least **1.5 GiB** of memory stays free
beyond the seller itself. Below that it keeps running but stays unlisted. The model needs memory too.

On Linux, membership in the `docker` group gives an account root-level control of the machine. When the
installer cannot use Docker it suggests adding your account to that group. Do that only if this account
may hold that power; otherwise let the installer set up the native seller.

You also need a little **devnet SOL** from the [devnet faucet](https://faucet.solana.com): about 0.02 SOL
on the owner address to register, and about 0.05 SOL on the fee payer if you charge for inference. The
installer prints both addresses. Never use mainnet funds or keys.

## Data that leaves your machine [#data-that-leaves-your-machine]

Release builds of the seller and the desktop app upload signed, content-free receipts to the Gyblos
metrics collector, `collector.gyblos.com`. Receipts have no opt-out. They also upload content-free
telemetry observations, which `GYBLOS_OBSERVATIONS=off` turns off. Neither contains prompts or answers.
See [Data and privacy](/en/reference/data-and-privacy) for the full list.
