La instalación predeterminada sirve **Qwen3 0.6B fijado mediante Ollama local**, con razonamiento `off`.
Es el modelo validado de extremo a extremo para este inicio. Estar en el catálogo o tener TOML válido
no significa que todos los modelos hayan sido probados.

## Reduce las cuotas gratuitas

Edita la entrada `[[offers]]` existente en `~/gyblos-seller/gyblos.toml`. Este ejemplo completo reduce
a la mitad la cuota total y baja la cuota por comprador. Deja la publicación desactivada intencionadamente;
si ya estás publicado, conserva tu ajuste `[discovery]` al cambiar solo las cuotas.

```toml
version = 1

[node]
network = "devnet"

[discovery]
publish = false

[[offers]]
model = "qwen3:0.6b"
reasoning = ["off"]
engine = { kind = "ollama", url = "http://127.0.0.1:11434/" }
free = { daily_token_cap = 100000, per_buyer_cap = 2000 }
```

Ambas cuotas son enteros positivos; la cuota por comprador no puede superar la total diaria. Cuentan
**entrada más salida** por día UTC. La admisión reserva la entrada más la salida máxima solicitada, por lo que
una solicitud puede rechazarse antes de que el saldo nominal llegue a cero. Un conteo final válido libera
la reserva no utilizada.

Los contadores están en memoria y se restablecen al reiniciar. El límite por comprador es una protección
parcial; no es facturación persistente ni garantiza impedir que alguien cree otra identidad de comprador.

## Valida y aplica

```sh
cd ~/gyblos-seller
docker compose run --rm seller gyblos config validate --config /config/gyblos.toml
```

Después de `OK`, aplica el cambio:

```sh
docker compose up -d --force-recreate seller
docker compose exec seller gyblos seller status
```

Comprueba `RUNNING` y el modelo ofrecido. Usa `seller status --online` si publicas.
Si falla, busca el código en [solución de problemas](/es/help/troubleshooting). La configuración se lee
al arrancar; editar el archivo por sí solo no cambia el vendedor en ejecución.

## Cambiar de modelo o motor

Cambiar `model` no descarga un modelo ni inicia un motor. El instalador solo descarga `qwen3:0.6b`.
Actualmente el inicio con Ollama acepta Qwen3 0.6B fijado, una URL raíz de loopback literal,
sin variable de API key y con razonamiento `off`. Conserva la URL de Docker `http://127.0.0.1:11434/`.
Los dos contenedores comparten espacio de red; un servicio del equipo anfitrión u otro contenedor tiene otra dirección.

También existen motores compatibles con OpenAI y Anthropic. Requieren tamaño de contexto explícito,
razonamiento `off` y un endpoint compatible para listar modelos además de generar. Anthropic exige una
variable de API key y una raíz de API sin `/v1`. Son opciones avanzadas, fuera del tutorial local.
Consulta la [referencia de configuración](/es/reference/configuration).

<Callout type="warn" title="Una oferta gratuita puede tener costes para ti">
  Un proveedor alojado puede cobrar al vendedor por las solicitudes. Guarda sus
  credenciales en variables de entorno, nunca en TOML. No actives un proveedor
  remoto sin entender sus costes y política de datos.
</Callout>

El daemon predeterminado de Docker no conecta la venta pagada. Añadir una tabla `price` no es una forma
admitida de convertir este inicio en servicio pagado. La validación pagada en devnet del proyecto es independiente.
