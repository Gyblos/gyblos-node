title: Cambia modelos y límites
description: Baja o sube tus límites gratuitos de tokens, ajusta la longitud de respuesta y de contexto, y conoce qué modelos y motores puede servir un vendedor.
---

El instalador prepara una oferta gratuita: **Qwen3 0.6B con Ollama**, con razonamiento `off`. Es el único
modelo admitido en la beta. La oferta se cambia en la entrada `[[offers]]` de `config.toml`:

| Tipo de instalación        | Ubicación de `config.toml`          |
| -------------------------- | ----------------------------------- |
| Vendedor Docker            | `~/gyblos-seller/config.toml`       |
| Vendedor nativo            | `~/.gyblos/config.toml`             |
| Vendedor nativo en Windows | `%USERPROFILE%\.gyblos\config.toml` |

El vendedor solo lee el archivo al iniciar. Después de cada edición, valídalo y aplícalo como se explica en
[Opera y actualiza](/es/sellers/operate#aplica-cambios-de-configuración-o-entorno).

## Límites gratuitos [#reduce-las-cuotas-gratuitas]

La línea `free` de la oferta fija cuántos tokens regala el vendedor. Este ejemplo reduce a la mitad el total
diario y baja el límite por comprador. Edita solo esa línea y conserva el resto de tu archivo, incluida tu
configuración de `[discovery]`:

```toml
version = 1

[node]
network = "devnet"

[discovery]
publish = false

[[offers]]
model = "qwen3:0.6b"
reasoning = ["off"]
engine = { kind = "ollama", url = "http://127.0.0.1:11434/" }
free = { daily_token_cap = 100000, per_buyer_cap = 2000 }
```

- `daily_token_cap` y `per_buyer_cap` son enteros positivos, y el límite por comprador no puede superar el total
  diario. Los valores del instalador son 200.000 y 50.000.
- Los dos cuentan tokens de **entrada más salida** por día UTC. La admisión reserva la entrada más la salida
  máxima pedida, así que una solicitud puede rechazarse antes de que el saldo llegue a cero. La parte no usada
  de la reserva se libera al terminar la respuesta.
- Los contadores viven en memoria y se reinician cuando se reinicia el vendedor. Los límites por comprador son
  de mejor esfuerzo: alguien puede crear otra identidad de comprador.

## Longitud de respuesta y contexto [#longitud-de-respuesta-y-contexto]

Dos ajustes opcionales deciden lo larga que puede ser una solicitud:

- `free.max_output_tokens`, en la línea `free`, fija la respuesta más larga que puede pedir una solicitud. El
  valor predeterminado es 4.096 y el máximo, 32.768.
- `context_tokens`, en la línea `engine`, fija el contexto del modelo. Con Ollama el valor predeterminado es
  8.192 y el rango va de 1.024 a 32.768.

Los agentes de programación envían preguntas de miles de tokens. Para atenderlos, sube `context_tokens` y usa
una máquina rápida, con Apple Silicon o GPU; un servidor solo con CPU puede ser demasiado lento para ellos. Cada
oferta mide qué tan rápido lee los prompts y rechaza, antes de recibir el prompt, las solicitudes que no
alcanzaría a leer a tiempo; así un servidor lento sigue atendiendo las más cortas. Por ejemplo:

```toml
[[offers]]
model = "qwen3:0.6b"
reasoning = ["off"]
engine = { kind = "ollama", url = "http://127.0.0.1:11434/", context_tokens = 32768 }
free = { daily_token_cap = 200000, per_buyer_cap = 50000, max_output_tokens = 8192 }
```

Todas las claves de una oferta están en la [referencia de configuración](/es/reference/configuration#campos-de-la-oferta).

## Modelos y motores [#cambiar-de-modelo-o-motor]

Cambiar `model` no descarga ningún modelo ni inicia ningún motor; el instalador solo descarga `qwen3:0.6b`.
Una oferta de Ollama solo arranca con:

- el modelo `qwen3:0.6b`;
- una URL literal de loopback como `http://127.0.0.1:11434/`, sin clave de API;
- razonamiento `off`.

Deja la URL del vendedor Docker en `http://127.0.0.1:11434/`: el vendedor comparte el espacio de red con su
propio contenedor de Ollama, así que un servicio del host u otro contenedor no responde en esa dirección.

También existen motores compatibles con OpenAI y con Anthropic para instalaciones avanzadas, fuera de esta
guía. Sus requisitos están en la
[referencia de configuración](/es/reference/configuration#compatibilidad-de-motores-al-iniciar).

<Callout type="warn" title="Una oferta gratuita también puede costarte dinero">
  Un proveedor de modelos alojado puede cobrarte por cada solicitud que atienda
  tu vendedor, y recibe los mensajes de los compradores. Lee sus precios y su
  política de datos antes de activarlo. Guarda las credenciales del proveedor en
  `seller.env`, nunca en `config.toml`.
</Callout>

Para cobrar por la oferta de Qwen3 en devnet en lugar de regalarla, consulta [Cobra](/es/sellers/get-paid).
