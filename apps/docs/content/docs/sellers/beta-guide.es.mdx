title: Guía de la beta para vendedores
description: Instala el nodo vendedor de Gyblos, revisa que esté sirviendo y regístralo con tu invitación.
---

Te invitaron a la beta de vendedores de Gyblos. Esta guía te lleva desde los archivos de tu invitación
hasta tener tu nodo listado en el descubrimiento. Toma unos 15 minutos, casi todo en descargas.

<Callout title="Beta en devnet">
  La beta funciona en la **devnet** de Solana. Tu nodo regala un modelo pequeño,
  con límites diarios. No se mueve dinero real.
</Callout>

## Qué necesitas

- **Tu invitación**, con tres cosas:
  - `install.sh`, el script de instalación;
  - un **token de relay**, que permite que tu nodo llegue a los relays de Gyblos;
  - un **código de invitación** que empieza con `gyb_` y se usa una sola vez para registrarte.
- **Una máquina que quede encendida.** Linux (x86-64 o ARM64) o macOS. Sirve un VPS pequeño.
- **Docker** con **Compose v2.17 o más nuevo**. En macOS, Docker Desktop. En Linux, Docker Engine con el
  plugin de compose y tu usuario en el grupo `docker`.
- **Al menos 4 GB de memoria.** El vendedor necesita 1,5 GB libres para arrancar, y el modelo corre al lado.
- **Algunos GB de disco** para las imágenes y el modelo.
- **Salida a internet.** No se abre ningún puerto: tu nodo se conecta hacia afuera, a los relays.

Mantén en privado el token de relay y el código de invitación. No los pegues en chats, issues ni capturas
de pantalla.

## Instalar

<Steps>
<Step>

### Corre el script

En la carpeta donde guardaste `install.sh`:

```sh
sh install.sh
```

Te pide el **token de relay**. El token no se muestra mientras lo escribes o lo pegas.

</Step>
<Step>

### Espera a que termine

El script trabaja en `~/gyblos-seller`:

1. escribe `compose.yaml`, `gyblos.toml` (tu oferta) y `seller.env` (tu token de relay, que solo tú
   puedes leer);
2. descarga la imagen del vendedor, Ollama y el modelo `qwen3:0.6b`;
3. crea las llaves de tu vendedor;
4. corre `gyblos doctor`, que revisa todo antes de arrancar;
5. arranca el vendedor.

Cuando termina con `The seller is running`, está listo. Doctor también muestra la **identidad de tu
vendedor**:

```text
Seller identity (public; `gyblos seller register` enrolls it in discovery):
  nodeId  4d789a89…
  owner   7is91kWV…
```

Los dos valores son públicos. Guárdalos: Gyblos te los puede pedir.

</Step>
<Step>

### Si se detiene con un error

Lee la línea marcada con `FAIL`, o la que empieza con `gyblos install:`: dice qué está mal y qué hacer. Corrígelo y vuelve
a correr `sh install.sh`. Repetirlo es seguro: conserva tus archivos y llaves y sigue donde se quedó.

</Step>
</Steps>

## Revisa que esté sirviendo

Todos los comandos de aquí en adelante se corren desde la carpeta de instalación:

```sh
cd ~/gyblos-seller
docker compose exec seller gyblos seller status
```

Mira la línea `Result:`:

| Resultado       | Qué significa                                                                                                        |
| --------------- | -------------------------------------------------------------------------------------------------------------------- |
| `RUNNING`       | El vendedor está funcionando y sirviendo.                                                                            |
| `STARTING`      | Todavía está arrancando. Espera un minuto y vuelve a revisar.                                                        |
| `FAILING`       | El último arranque falló. La línea siguiente dice el paso, el código de error y qué hacer.                           |
| `STOPPED`       | El contenedor está arriba, pero el vendedor no está corriendo. Corre `docker compose up -d --force-recreate seller`. |
| `NOT_CONFIRMED` | No se pudo confirmar el servicio. Revisa `docker compose ps`.                                                        |

Si el comando mismo dice que el servicio no está corriendo o se está reiniciando, el vendedor se detuvo por un
error: lee `docker compose logs seller`, corrige la causa y arráncalo con `docker compose up -d`.

## Regístrate con tu invitación

El registro permite que tu vendedor aparezca en el descubrimiento de Gyblos, donde lo encuentran los
compradores. Usa tu código una vez:

```sh
cd ~/gyblos-seller
docker compose exec seller gyblos seller register
```

Pega el código cuando te lo pida. Se ve en pantalla mientras lo pegas, así que hazlo donde nadie vea tu
pantalla. `Registered: this seller may now publish.` significa que funcionó. Si lo
vuelves a correr con el mismo código, responde `Already registered`.

El código queda ligado a las llaves de tu vendedor. Si las borras (`docker compose down -v`), el mismo código ya
no funciona.

<Callout type="warn" title="Paso en la blockchain">
  El descubrimiento también revisa que tu nodo esté inscrito en la devnet de
  Solana. Estamos terminando ese paso. Si register responde
  `DISCOVERY_IDENTITY_NOT_REGISTERED`, tu nodo todavía no está inscrito: envía
  al equipo de Gyblos el `nodeId` y el `owner` de la instalación y guarda tu
  código. No se gastó, pero igual puede vencer; si vence, pide uno nuevo.
</Callout>

## Publica tu oferta

Las instalaciones nuevas empiezan sin listarse. Cuando estés registrado, abre `~/gyblos-seller/gyblos.toml`
y cambia:

```toml
[discovery]
publish = true
```

Aplica el cambio:

```sh
cd ~/gyblos-seller
docker compose up -d --force-recreate seller
```

Después de un minuto, revisa que el descubrimiento te liste:

```sh
docker compose exec seller gyblos seller status --online
```

Debería decir `listed in the index`.

## Qué ofrece tu nodo

La oferta por defecto en `gyblos.toml` regala `qwen3:0.6b`:

- hasta **200.000 tokens al día** en total;
- hasta **5.000 tokens al día** por cada comprador.

Los contadores se reinician cuando el vendedor se reinicia. Puedes bajar estos límites en la sección
`[[offers]]`. Aplica los cambios con
`docker compose up -d --force-recreate seller`.

Los prompts se procesan en tu máquina, así que tu nodo puede leerlos. No guardes ni compartas lo que envían
los compradores. El descubrimiento publica tu `nodeId`, tu `owner`, tu modelo y un precio cero.

## Comandos del día a día

Desde `~/gyblos-seller`:

| Qué                              | Comando                                           |
| -------------------------------- | ------------------------------------------------- |
| Estado                           | `docker compose exec seller gyblos seller status` |
| Ver los logs en vivo             | `docker compose logs -f seller`                   |
| Detener                          | `docker compose stop seller`                      |
| Arrancar                         | `docker compose up -d`                            |
| Aplicar un `gyblos.toml` editado | `docker compose up -d --force-recreate seller`    |
| Actualizar a la última beta      | `docker compose pull && docker compose up -d`     |

Al detenerlo, tu oferta sale del descubrimiento en menos de dos minutos.

<Callout type="error" title="Tus llaves viven en un volumen de Docker">
  `docker compose down -v` **borra las llaves de tu vendedor**, y con ellas tu
  identidad. Usa `docker compose down` (sin `-v`) para quitar los contenedores y
  conservar las llaves.
</Callout>

## Solución de problemas

| Ves                                                            | Qué hacer                                                                                                                                                                                                                |
| -------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `Docker is not installed` o `Docker Compose v2 is missing`     | Instala Docker con el plugin de compose (v2.17 o más nuevo) y vuelve a correr el script.                                                                                                                                 |
| `Docker is not running`                                        | Abre Docker Desktop, o arranca el servicio de Docker en Linux, y vuelve a correr el script.                                                                                                                              |
| `Docker Compose … is too old`                                  | Actualiza Docker o el plugin de compose a v2.17 o más nuevo.                                                                                                                                                             |
| `The relay token is empty…` o `must have 32 to 512 characters` | Copia otra vez el token de relay de tu invitación, sin nada antes ni después.                                                                                                                                            |
| `FAILING` con `SELLER_RELAY_OFFLINE`                           | Ningún relay respondió. Revisa que la máquina tenga internet. Si el token puede estar mal, borra `seller.env` y vuelve a correr `sh install.sh` para ingresarlo; nunca muestres `seller.env` en una pantalla compartida. |
| `Ollama did not start`                                         | Corre `cd ~/gyblos-seller && docker compose logs ollama`. Suele ser falta de memoria o de disco.                                                                                                                         |
| El vendedor falla después de que Ollama se reinició solo       | Corre `docker compose restart seller`.                                                                                                                                                                                   |
| `DISCOVERY_INVITE_INVALID`                                     | El código está mal, ya se usó o venció. Pide uno nuevo a Gyblos.                                                                                                                                                         |
| `DISCOVERY_RATE_LIMITED` o `DISCOVERY_UNAVAILABLE`             | El descubrimiento está ocupado. Intenta de nuevo en unos minutos.                                                                                                                                                        |

Si te quedas atascado, envía al equipo de Gyblos lo que muestra
`docker compose exec seller gyblos seller status`. Nunca incluye tu token de relay ni tus llaves.
