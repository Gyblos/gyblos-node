title: Inicio rápido
description: Instala tu primer vendedor gratuito de Docker, compruébalo y continúa con el registro.

Usa esta guía después de revisar los [requisitos de la beta](/es/getting-started/beta).
Mantén privados el token de relay y el código de invitación. Descargar las imágenes y el modelo ocupa
la mayor parte de la instalación; el tiempo depende de tu conexión y equipo.

## Antes de empezar

Necesitas una invitación con `install.sh` y un token privado de relay, Linux o macOS,
Docker con Compose v2.17 o posterior, al menos 4 GB de memoria e internet saliente.
Revisa los [requisitos completos](/es/getting-started/beta), incluido el margen de memoria, antes de instalar.

## Instala [#instala-el-vendedor]

Descarga el instalador oficial, léelo si quieres y ejecútalo:

```sh
curl -fsSL https://gyblos.com/install.sh -o install.sh
sh install.sh
```

El instalador fija una versión firmada de la imagen del vendedor por versión y digest. Con
[cosign](https://docs.sigstore.dev/cosign/system_config/installation/) instalado muestra
`Verified the Gyblos release signature` antes de descargarla; sin cosign indica que omitió la comprobación.
Para verificar la imagen tú mismo o preparar cada archivo a mano, consulta [Instala sin el script](/es/sellers/manual-install).

El token de relay permanece oculto mientras lo introduces. El script trabaja en `~/gyblos-seller`, salvo
que hayas elegido otro directorio. Crea `compose.yaml`, `gyblos.toml` y el archivo privado `seller.env`,
descarga Ollama y `qwen3:0.6b`, crea las llaves en un volumen de Docker, instala el tokenizador,
ejecuta `gyblos doctor` e inicia el vendedor.

### Identidad pública

Cuando muestre `The seller is running`, comprueba el estado. Guarda la identidad pública que muestra doctor:

```text
Seller identity (public; `gyblos seller register` enrolls it in discovery):
  nodeId  4d789a89…
  owner   7is91kWV…
```

Son ejemplos abreviados, no llaves ni valores para copiar en la configuración. El registro en descubrimiento
es distinto de la inscripción en cadena que comprueba el índice.

### Problemas de instalación

Si la instalación se detiene, lee la línea `FAIL` o `gyblos install:` y consulta
[solución de problemas](/es/help/troubleshooting). Corrige la causa antes de repetir el script.
Volver a ejecutarlo conserva la configuración, el archivo del token y la identidad; no restablece esos archivos.

## Comprueba el estado [#confirma-el-estado-del-servicio]

Ejecuta los comandos desde la carpeta de instalación:

```sh
cd ~/gyblos-seller
docker compose exec seller gyblos seller status
```

| Resultado       | Significado y siguiente paso                                                        |
| --------------- | ----------------------------------------------------------------------------------- |
| `RUNNING`       | El servicio está en ejecución. Continúa con el registro.                            |
| `STARTING`      | Espera un momento y vuelve a consultar.                                             |
| `FAILING`       | Lee la fase y el código; sigue la entrada correspondiente en solución de problemas. |
| `STOPPED`       | Ejecuta `docker compose up -d --force-recreate seller`.                             |
| `NOT_CONFIRMED` | Comprueba `docker compose ps`; no se pudo confirmar el servicio.                    |

### Diagnóstico

Si el contenedor está detenido o reiniciándose, `exec` no puede funcionar. Ejecuta el diagnóstico independiente:

```sh
cd ~/gyblos-seller
docker compose run --rm seller gyblos doctor
```

Que doctor termine correctamente no demuestra una solicitud completa de un comprador. Después del registro
y la publicación, pide ayuda por el canal de tu invitación si necesitas coordinar una comprobación externa gratuita.

## Siguientes pasos [#completa-el-alta]

Tu nodo empieza **sin publicar**. Sigue [Registra y publica](/es/sellers/register-publish) para usar tu
invitación y activar la publicación. Si falta la inscripción en Solana, el registro interactivo estima el
coste en SOL de devnet y pregunta antes de un nuevo envío firmado; revisa esa guía antes de continuar. La oferta predeterminada permite 200.000 tokens de entrada más salida
por día UTC, con 5.000 por comprador; revisa [Modelos y ofertas](/es/sellers/models-offers) antes de cambiarlos.

<Callout type="error" title="Conserva tu identidad">
  `docker compose down -v` elimina los volúmenes persistentes y las llaves de tu
  vendedor. Detén el servicio con `docker compose stop seller`. Lee la guía de
  identidad antes de mover o borrar datos.
</Callout>

**Siguiente:** [Registra y publica](/es/sellers/register-publish).
