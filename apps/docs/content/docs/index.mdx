Gyblos is a peer-to-peer market for AI inference: sellers serve a model from their own machine and buyers
reach them directly. Start here if you received an invitation to run a seller in the beta.

## Start with your seller

You need the `install.sh`, relay token and invite code from your invitation, a machine that stays on,
and Docker with Compose v2.17 or later. The guide covers installation, checks, registration and
publishing your offer.

## Current scope

This documentation covers the **free Docker seller** shipped with the invitation. Gyblos runs on Solana
**devnet** during this beta; no real money moves. These instructions do not establish mainnet readiness.

The guide includes everyday commands, token limits and troubleshooting. For help, reply through the
same channel where you received your invitation. Keep your relay token, invite code and keys private.
