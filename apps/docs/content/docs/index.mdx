title: Gyblos documentation
description: Gyblos is a peer-to-peer network for AI inference. Use models as a buyer or serve one as a seller.
---

Gyblos is a peer-to-peer network for AI inference. **Sellers** run a model on their own machine and
offer it to the network. **Buyers** chat with those models in the desktop app, or call them from their own
programs through OpenAI- and Anthropic-compatible APIs.

The beta runs on Solana **devnet**. Free offers need no wallet. Priced offers are paid in devnet USDC,
which has no market value. Selling requires an invite code.
