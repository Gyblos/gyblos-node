Gyblos es un mercado entre pares para inferencia de IA: los vendedores sirven un modelo desde su propia
máquina y los compradores llegan directo a ellos. Empieza aquí si recibiste una invitación para
operar un vendedor en la beta.

## Empieza con tu vendedor

Necesitas el `install.sh`, el token de relay y el código de tu invitación, una máquina que quede
encendida y Docker con Compose v2.17 o más nuevo. La guía cubre instalación, comprobaciones,
registro y publicación de tu oferta.

## Alcance actual

Esta documentación cubre el **vendedor gratuito en Docker** que se entrega con la invitación.
Durante esta beta, Gyblos funciona en la **devnet** de Solana; no se mueve dinero real.
Estas instrucciones no acreditan preparación para mainnet.

La guía incluye comandos cotidianos, límites de tokens y solución de problemas. Para pedir ayuda,
responde por el mismo canal donde recibiste tu invitación. Mantén privados tu token de relay,
código de invitación y llaves.
