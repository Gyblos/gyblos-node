The Gyblos app lets you chat with AI models served by people on the Gyblos network, from your own
computer. You do not need a seller's address, a relay key or a terminal.

## Download [#download]

Get the file for your system from the
[latest release](https://github.com/Gyblos/gyblos-node/releases/latest), under **Assets**:

| System                             | File                                        |
| ---------------------------------- | ------------------------------------------- |
| macOS (Apple Silicon: M1 or newer) | `gyblos-desktop-<version>-darwin-arm64.zip` |
| Windows 10/11 (x64)                | `gyblos-desktop-<version>-win32-x64.zip`    |
| Linux (Ubuntu, Debian; x64)        | `gyblos-desktop-<version>-linux-x64.deb`    |
| Other Linux (x64)                  | `gyblos-desktop-<version>-linux-x64.tar.gz` |

There is no build for Intel Macs yet. Each file has a `.sha256` next to it; to check a download, put both
in one folder and run `shasum -a 256 -c <file>.sha256` (macOS, Linux) or compare the output of
`certutil -hashfile <file> SHA256` (Windows).

## Install and open the first time [#install]

During the beta the app is **not signed** by Apple or Microsoft, so your system asks once before opening
it. This is expected; after the first time it opens normally.

### macOS [#macos]

1. Open the `.zip`; it unpacks **Gyblos**. Drag it to **Applications**.
2. Open Gyblos. macOS says it cannot verify the developer; choose **Done**.
3. Open **System Settings → Privacy & Security**, scroll to the message about Gyblos and choose
   **Open Anyway**, then confirm with your password.

### Windows [#windows]

1. Right-click the `.zip` and choose **Extract All**.
2. In the extracted folder, open `gyblos-desktop.exe`.
3. If Windows shows "Windows protected your PC", choose **More info**, then **Run anyway**.

### Linux [#linux]

On Ubuntu or Debian, install the `.deb` and open **Gyblos** from the applications menu:

```sh
sudo apt install ./gyblos-desktop-<version>-linux-x64.deb
```

On other distributions, unpack the `.tar.gz` and run `./gyblos-desktop` inside the folder.

## Using it [#using-it]

The app sets itself up the first time: it creates its own buyer identity in its own folder, separate from
any seller on the same computer, and uses the sellers registered in the Gyblos index, checking each
seller's identity on Solana devnet before sending anything. Answers are free during the beta.

Your messages reach the seller whose machine runs the model, and that seller can read them. Do not send
passwords, keys or other secrets.

To connect your own programs or coding agents instead, see [Use Gyblos from your code](/en/buyers/use-from-code).
