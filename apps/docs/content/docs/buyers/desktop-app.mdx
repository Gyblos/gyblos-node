The Gyblos desktop app lets you chat with models that sellers on the Gyblos network serve. Answers from
free offers cost nothing and need no wallet funding. For most buyers, the app is the only setup you need.

The app sets itself up the first time it opens. It keeps its data in its own private folder (`userData`),
works without a relay token, and starts with a zero spending budget, so it never pays for an answer unless
you authorize it.

## Download [#download]

Get the file for your system from the
[latest release](https://github.com/Gyblos/gyblos-node/releases/latest), under **Assets**:

| System                             | File                                        |
| ---------------------------------- | ------------------------------------------- |
| macOS (Apple Silicon: M1 or newer) | `gyblos-desktop-<version>-darwin-arm64.zip` |
| Windows 10/11 (x64)                | `gyblos-desktop-<version>-win32-x64.zip`    |
| Linux (Ubuntu, Debian; x64)        | `gyblos-desktop-<version>-linux-x64.deb`    |
| Other Linux (x64)                  | `gyblos-desktop-<version>-linux-x64.tar.gz` |

There is no build for Intel Macs. Each file has a `.sha256` file next to it. To check a download, put both
in one folder and run `shasum -a 256 -c <file>.sha256` (macOS, Linux), or compare the output of
`certutil -hashfile <file> SHA256` (Windows).

## Install and open the first time [#install]

During the beta, Apple and Microsoft have not signed the app, so your system asks once before it opens.
After that it opens normally.

### macOS [#macos]

1. Open the `.zip`, enter `Gyblos-darwin-arm64`, and drag **Gyblos.app** to **Applications**.
2. Open Gyblos. macOS says it cannot verify the developer; choose **Done**.
3. Open **System Settings → Privacy & Security**, scroll to the message about Gyblos, choose
   **Open Anyway**, and confirm with your password.
4. Chat opens. The app creates its data folder by itself; you don't choose or open a folder, and it
   doesn't ask to unlock a wallet.

After an update, macOS may warn you again before the app opens. Opening the app never asks for
"Gyblos Safe Storage": wallet access is a separate step, described in [Protected wallet](#protected-wallet).

### Windows [#windows]

1. Right-click the `.zip` and choose **Extract All**.
2. Enter `gyblos-desktop-win32-x64` inside the extracted folder and open `gyblos-desktop.exe`.
3. If Windows shows "Windows protected your PC", choose **More info**, then **Run anyway**.

### Linux [#linux]

On Ubuntu or Debian, install the `.deb` and open **Gyblos** from the applications menu:

```sh
sudo apt install ./gyblos-desktop-<version>-linux-x64.deb
```

On other distributions, unpack the `.tar.gz` and run `./gyblos-desktop` inside the folder.

## Chat [#using-it]

1. Open **Chat**.
2. Write a message and send it.

The answer appears as the text arrives. The app finds a registered seller that offers the model for free,
checks the seller's identity, and only then sends your message. The default model is `qwen3-0.6b`. The app
needs to reach the discovery index, the Solana devnet RPC and the network; if no seller is available, you
get an error, never a made-up reply.

While an answer is running, the send button becomes **Stop response**; you can also press **Esc**.
Stopping keeps the partial text and doesn't resend your message. An interrupted answer is not marked as
complete.

The seller that runs the model can read your messages, and so can its engine provider, if it uses one.
Don't send passwords, keys or other secrets. See [Data and privacy](/en/reference/data-and-privacy).

## Use Gyblos from other tools [#api-keys]

**Connections** gives your own programs and coding agents access to Gyblos through the app, with an API
key and a spending limit. Tools can use the OpenAI Chat Completions, OpenAI Responses and Anthropic
Messages APIs.

1. Open **Connections**. If it asks you to connect your buyer, choose **Go to Payments** and start the
   local buyer there.
2. Under **Create an API key**, enter a **Name** and a **Spend limit**, then choose **Create API key**.
   The limit is the total this key may spend, in devnet USDC, with no automatic reset. A limit of `0`
   allows free models only.
3. Choose **Copy Base URL** and **Copy API key**, and paste both into your tool. You can copy the key only
   in the app session that created it. A tool that already has it keeps working after a restart.
4. Optional: choose **Connect agent** to set up OpenCode, pi, Codex CLI or Claude Code. The app shows the
   configuration and can write it for you, except for Claude Code, which you copy into your shell. The
   configuration reads the key from the `GYBLOS_API_KEY` variable: set it in the shell that starts the
   agent.

In **Connections**, a key with a zero spend limit is labelled **Free only**. The eye button reveals
that key only when you request it, in the app session that created it. Hide it before sharing your
screen. Hiding, changing the selected key or revoking it removes the visible value. No secret is
included in periodic status replies, saved agent configuration or chat history. After restarting the
app, a key already saved in your agent still works, but the app cannot recover its secret for display.

Keep Gyblos open while your tools use it. **Revoke key** stops new requests with that key; what it
already spent stays recorded. Chat has its own budget and doesn't use a key's limit.

For SDK examples, supported options and errors, see [Connect your coding tools](/en/buyers/use-from-code).

## Payments [#payments]

Free answers need no funding or transaction, and no wallet. The local buyer's identity is separate from
the protected wallet in **Payments**.

A priced answer needs a budget that you authorize in **Payments**; the app never authorizes one on its
own. If the outcome of a paid request is uncertain, the app blocks new messages until you review it in
**Payments**. Stopping a response doesn't prove that no charge occurred.

If the local buyer fails to start, choose **Payments → Retry local buyer**. That retries startup only: the
app never resends a failed message on its own. **Activity** keeps a history of your sessions and their
payment references.

## Protected wallet [#protected-wallet]

The wallet starts locked, and free chat never needs it. To use it:

1. Open **Payments → Wallet details** and choose **Set up or unlock wallet**.
2. Gyblos explains what happens next before it touches your system's secure storage. Choose **Continue**
   to go on, or **Cancel** to keep chatting without the wallet.
3. Your system may then ask for access:
   - **macOS**: Keychain uses "Gyblos Safe Storage" to protect the wallet's encryption key. Enter your
     Mac password only in the macOS dialog, never in a Gyblos form.
   - **Windows**: protection normally works through your Windows account, without a prompt.
   - **Linux**: GNOME Keyring or KWallet may ask to be unlocked. Without a supported secret store, the
     wallet stays unavailable; the app never stores its keys unprotected.

Unlocking doesn't authorize a payment or enable funding. Existing wallets and recovery records are kept.
The app asks for a file only when you choose to back up or restore the wallet. If a system dialog is
open when you quit, the app may wait for it: answer or cancel it to finish closing.

## Updates [#updates]

The app checks for updates when it starts and every five minutes while it stays open. When a newer build
for your system is published, it shows a notice. **View update** opens that release on GitHub; the app
never downloads or installs anything by itself. The check sends no identity or chat content. To turn it
off, see [Data and privacy](/en/reference/data-and-privacy#update-checks).

## Where the app keeps your data [#data]

The app keeps your conversations, activity and its local buyer in a `gyblos-desktop` folder, and, once
you set it up, its wallet in a `gyblos-wallet` folder, both in your system's application-data folder:

| System  | Folder                          |
| ------- | ------------------------------- |
| macOS   | `~/Library/Application Support` |
| Windows | `%APPDATA%`                     |
| Linux   | `~/.config`                     |

Release builds also upload signed, content-free receipts and telemetry observations; see
[Data and privacy](/en/reference/data-and-privacy).

To uninstall, delete the app. The data folders stay until you delete them.

<Callout type="warn" title="Deleting gyblos-wallet deletes your wallet">
  Deleting the `gyblos-wallet` folder permanently deletes the wallet's keys and
  any funds they hold. It cannot be undone. Back up the wallet from **Payments**
  first, or keep the folder.
</Callout>
