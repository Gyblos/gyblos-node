---
title: App de escritorio
description: Descarga la app de Gyblos para macOS, Windows o Linux, ábrela la primera vez y conversa con modelos de la red.
---

El comprador arranca automáticamente en la carpeta privada de la app (`userData` como `GYBLOS_HOME`).
No tienes que elegir una carpeta: funciona sin token de relay. Un perfil nuevo crea una configuración
solo gratuita, con presupuesto y precios máximos en cero. Busca un vendedor registrado mediante discovery
y verificación 8004 independiente. Conserva la configuración y los registros pendientes existentes.

## Descargar [#descargar]

Baja el archivo de tu sistema desde la
[última versión](https://github.com/Gyblos/gyblos-node/releases/latest), en **Assets**:

| Sistema                               | Archivo                                     |
| ------------------------------------- | ------------------------------------------- |
| macOS (Apple Silicon: M1 o más nuevo) | `gyblos-desktop-<versión>-darwin-arm64.zip` |
| Windows 10/11 (x64)                   | `gyblos-desktop-<versión>-win32-x64.zip`    |
| Linux (Ubuntu, Debian; x64)           | `gyblos-desktop-<versión>-linux-x64.deb`    |
| Otro Linux (x64)                      | `gyblos-desktop-<versión>-linux-x64.tar.gz` |

Todavía no hay versión para Mac con Intel. Cada archivo tiene un `.sha256` al lado; para comprobar una
descarga, deja ambos en una carpeta y ejecuta `shasum -a 256 -c <archivo>.sha256` (macOS, Linux) o compara
lo que muestra `certutil -hashfile <archivo> SHA256` (Windows).

## Instalar y abrir la primera vez [#instalar]

Durante la beta la app **no está firmada** por Apple ni Microsoft, así que tu sistema pregunta una vez antes
de abrirla. Es normal; después de la primera vez se abre sin preguntar.

### macOS [#macos]

1. Abre el `.zip`, entra en `Gyblos-darwin-arm64` y arrastra **Gyblos.app** a **Aplicaciones**.
2. Abre Gyblos. macOS dice que no puede verificar al desarrollador; elige **OK**.
3. Abre **Configuración del Sistema → Privacidad y seguridad**, baja hasta el mensaje sobre Gyblos y elige
   **Abrir de todas formas**; confirma con tu contraseña.
4. Después macOS pide permiso para que Gyblos use la llave "Gyblos Safe Storage" de tu llavero. Escribe
   la contraseña de tu Mac y elige **Permitir siempre**. La app protege su wallet con esa llave. Mientras
   la pregunta está abierta, la app no se puede cerrar y su wallet aparece como no disponible.

Como la app de la beta no está firmada, macOS repite los pasos 2 a 4 después de cada actualización.

### Windows [#windows]

1. Haz clic derecho en el `.zip` y elige **Extraer todo**.
2. Entra en `gyblos-desktop-win32-x64` dentro de la carpeta extraída y abre `gyblos-desktop.exe`.
3. Si Windows muestra "Windows protegió su PC", elige **Más información** y luego **Ejecutar de todas
   formas**.

### Linux [#linux]

En Ubuntu o Debian, instala el `.deb` y abre **Gyblos** desde el menú de aplicaciones:

```sh
sudo apt install ./gyblos-desktop-<version>-linux-x64.deb
```

En otras distribuciones, descomprime el `.tar.gz` y ejecuta `./gyblos-desktop` dentro de la carpeta.

## Usarla [#usarla]

Abre **Chat**, escribe un mensaje y envíalo. El primer arranque prepara `buyer/` de forma privada en
la carpeta de datos de la app, separada del CLI y del vendedor. El modelo inicial es `qwen3-0.6b`;
necesita un vendedor verificado, disponible y gratuito para ese modelo. Discovery, la RPC de identidad
y la red deben estar accesibles. Si no lo están, se muestra un error, nunca una respuesta simulada.

La respuesta aparece a medida que llega el texto. Durante la generación, el botón de enviar cambia a
**Stop response**; también puedes pulsar **Esc**. Al detener, se conserva el texto parcial y no se
reenvía el prompt. Una respuesta interrumpida no se marca como completa. Si el cobro de un pedido pagado
sigue siendo incierto, permanece bloqueado para revisión en **Payments**: detenerlo no demuestra que
no se haya cobrado.

Estas respuestas gratuitas no requieren fondos ni transacciones. La identidad local del comprador
es distinta de la wallet protegida que aparece en Settings. Una configuración o conexión de precio
positivo sigue necesitando autorización explícita: el arranque no autoriza un presupuesto positivo
ni borra registros pendientes.

Si falla el inicio, **Payments → Retry local buyer** permite reintentar solo el arranque. Una inferencia
fallida nunca se reenvía automáticamente. Conectar otro comprador ya iniciado queda como opción avanzada.

Cuando se publica una versión de escritorio posterior para tu sistema, aparece un aviso de actualización.
**View update** abre esa versión en GitHub; no descarga ni instala nada automáticamente. Esta consulta
pública y acotada no envía tu identidad ni conversaciones. Los fallos de red son silenciosos; se puede
desactivar con `GYBLOS_UPDATE_CHECK=0`.

El vendedor que ejecuta el modelo puede leer tus mensajes. El cifrado del transporte no los oculta
frente a ese vendedor. No envíes contraseñas, claves ni otros secretos.

Para conectar tus programas o agentes, consulta [Usa Gyblos desde tu código](/es/buyers/use-from-code).
