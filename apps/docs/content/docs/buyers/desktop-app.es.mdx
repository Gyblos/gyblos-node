title: App de escritorio

La app de escritorio de Gyblos te permite chatear con modelos que sirven los vendedores de la red Gyblos.
Las respuestas de ofertas gratis no cuestan nada y no necesitan fondos en una billetera. Para la mayoría de
los compradores, la app es todo lo que necesitas.

La app se configura sola la primera vez que la abres. Guarda sus datos en su propia carpeta privada
(`userData`), funciona sin token de relay y empieza con un presupuesto de gasto en cero, así que nunca paga
una respuesta salvo que tú lo autorices.

## Descarga [#descargar]

Descarga el archivo para tu sistema desde la
[última versión](https://github.com/Gyblos/gyblos-node/releases/latest), en **Assets**:

| Sistema                               | Archivo                                     |
| ------------------------------------- | ------------------------------------------- |
| macOS (Apple Silicon: M1 o más nuevo) | `gyblos-desktop-<version>-darwin-arm64.zip` |
| Windows 10/11 (x64)                   | `gyblos-desktop-<version>-win32-x64.zip`    |
| Linux (Ubuntu, Debian; x64)           | `gyblos-desktop-<version>-linux-x64.deb`    |
| Otro Linux (x64)                      | `gyblos-desktop-<version>-linux-x64.tar.gz` |

No hay versión para Mac con Intel. Cada archivo tiene al lado un archivo `.sha256`. Para comprobar una
descarga, pon ambos en una carpeta y ejecuta `shasum -a 256 -c <file>.sha256` (macOS, Linux), o compara la
salida de `certutil -hashfile <file> SHA256` (Windows).

## Instala y ábrela por primera vez [#instalar]

Durante la beta, Apple y Microsoft no han firmado la app, así que tu sistema pregunta una vez antes de
abrirla. Después se abre con normalidad.

### macOS [#macos]

1. Abre el `.zip`, entra en `Gyblos-darwin-arm64` y arrastra **Gyblos.app** a **Aplicaciones**.
2. Abre Gyblos. macOS dice que no puede verificar al desarrollador; elige **OK**.
3. Abre **Configuración del Sistema → Privacidad y seguridad**, baja hasta el mensaje sobre Gyblos, elige
   **Abrir de todas formas** y confirma con tu contraseña.
4. Se abre el Chat. La app crea su carpeta de datos sola; no eliges ni abres ninguna carpeta, y no te pide
   desbloquear una billetera.

Después de una actualización, macOS puede volver a avisarte antes de abrir la app. Abrir la app nunca pide
"Gyblos Safe Storage": el acceso a la billetera es un paso aparte, descrito en
[Billetera protegida](#billetera-protegida).

### Windows [#windows]

1. Haz clic derecho en el `.zip` y elige **Extraer todo**.
2. Entra en `gyblos-desktop-win32-x64` dentro de la carpeta extraída y abre `gyblos-desktop.exe`.
3. Si Windows muestra "Windows protegió su PC", elige **Más información** y luego **Ejecutar de todas
   formas**.

### Linux [#linux]

En Ubuntu o Debian, instala el `.deb` y abre **Gyblos** desde el menú de aplicaciones:

```sh
sudo apt install ./gyblos-desktop-<version>-linux-x64.deb
```

En otras distribuciones, descomprime el `.tar.gz` y ejecuta `./gyblos-desktop` dentro de la carpeta.

## Chat [#usarla]

1. Abre **Chat**.
2. Escribe un mensaje y envíalo.

La respuesta aparece a medida que llega el texto. La app busca un vendedor registrado que ofrezca el modelo
gratis, comprueba su identidad y solo entonces envía tu mensaje. El modelo por defecto es `qwen3-0.6b`. La
app necesita llegar al índice de descubrimiento, al RPC de Solana devnet y a la red; si no hay ningún
vendedor disponible, recibes un error, nunca una respuesta inventada.

Mientras una respuesta está en curso, el botón de enviar pasa a ser **Stop response**; también puedes pulsar
**Esc**. Detenerla conserva el texto parcial y no reenvía tu mensaje. Una respuesta interrumpida no se marca
como completa.

El vendedor que ejecuta el modelo puede leer tus mensajes, y también su proveedor de motor, si usa uno. No
envíes contraseñas, llaves ni otros secretos. Consulta [Datos y privacidad](/es/reference/data-and-privacy).

## Usa Gyblos desde otras herramientas [#llaves-de-api]

Para el comprador gestionado por la app, **Connections → Connect agent** usa el puerto local fijo `4033`: reiniciar Gyblos conserva
la misma Base URL. Si está ocupado, detén el otro servicio local y reintenta el comprador;
Gyblos no elige otro puerto de forma silenciosa. Las configuraciones generadas por versiones anteriores
con un puerto variable deben copiarse o escribirse de nuevo una vez. Comprueba la Base URL en Connections.
Un comprador externo conectado explícitamente conserva su propia Base URL.

**Connections** da a tus propios programas y agentes de código acceso a Gyblos a través de la app, con una
API key y un límite de gasto. Las herramientas pueden usar las API OpenAI Chat Completions, OpenAI Responses
y Anthropic Messages.

1. Abre **Connections**. Si te pide conectar tu comprador, elige **Go to Payments** y arranca ahí el
   comprador local.
2. En **Create an API key**, escribe un **Name** y un **Spend limit**, y elige **Create API key**. El límite
   es el total que puede gastar esta llave, en USDC de devnet, sin reinicio automático. Un límite de `0`
   permite solo modelos gratis.
3. Elige **Copy Base URL** y **Copy API key**, y pega ambos en tu herramienta. Solo puedes copiar la llave en
   la sesión de la app que la creó. Una herramienta que ya la tiene sigue funcionando después de reiniciar.
4. Opcional: elige **Connect agent** para configurar OpenCode, pi, Codex CLI o Claude Code. La app muestra la
   configuración y puede escribirla por ti, salvo para Claude Code, que copias en tu terminal. La
   configuración lee la llave de la variable `GYBLOS_API_KEY`: defínela en la terminal que arranca el agente.

Mantén Gyblos abierto mientras tus herramientas lo usan. **Revoke key** detiene las solicitudes nuevas con
esa llave; lo que ya gastó queda registrado. El Chat tiene su propio presupuesto y no usa el límite de una
llave.

Para ejemplos con SDK, opciones admitidas y errores, consulta [Conecta tus herramientas de código](/es/buyers/use-from-code).

## Pagos [#pagos]

Las respuestas gratis no necesitan fondos, transacciones ni billetera. La identidad del comprador local es
distinta de la billetera protegida de **Payments**.

Una respuesta con precio necesita un presupuesto que autorizas en **Payments**; la app nunca lo autoriza
sola. Si el resultado de una solicitud pagada es incierto, la app bloquea los mensajes nuevos hasta que lo
revises en **Payments**. Detener una respuesta no prueba que no hubo cobro.

Si el comprador local no arranca, elige **Payments → Retry local buyer**. Eso solo reintenta el arranque: la
app nunca reenvía sola un mensaje que falló. **Activity** guarda el historial de tus sesiones y sus
referencias de pago.

## Billetera protegida [#billetera-protegida]

La billetera empieza bloqueada, y el chat gratis nunca la necesita. Para usarla:

1. Abre **Payments → Wallet details** y elige **Set up or unlock wallet**.
2. Gyblos te explica qué va a pasar antes de tocar el almacenamiento seguro de tu sistema. Elige
   **Continue** para seguir, o **Cancel** para seguir chateando sin la billetera.
3. Después tu sistema puede pedirte acceso:
   - **macOS**: el llavero usa "Gyblos Safe Storage" para proteger la llave de cifrado de la billetera.
     Escribe la contraseña de tu Mac solo en el diálogo de macOS, nunca en un formulario de Gyblos.
   - **Windows**: la protección normalmente funciona con tu cuenta de Windows, sin preguntar.
   - **Linux**: GNOME Keyring o KWallet puede pedirte desbloquearlo. Sin un almacén de secretos compatible,
     la billetera queda no disponible; la app nunca guarda sus llaves sin protección.

Desbloquearla no autoriza ningún pago ni habilita fondos. Las billeteras y los registros de recuperación que
ya existen se conservan. La app solo te pide un archivo cuando eliges hacer una copia o restaurar la
billetera. Si hay un diálogo del sistema abierto cuando cierras la app, puede esperar a que termine:
respóndelo o cancélalo para terminar de cerrarla.

## Actualizaciones [#actualizaciones]

La app busca actualizaciones al iniciar y cada cinco minutos mientras sigue abierta. Cuando se publica una
versión más nueva para tu sistema, muestra un aviso. **View update** abre esa versión en GitHub; la app nunca
descarga ni instala nada por su cuenta. La búsqueda no envía identidad ni contenido de chats. Para
desactivarla, consulta [Datos y privacidad](/es/reference/data-and-privacy#búsqueda-de-actualizaciones).

## Dónde guarda tus datos la app [#datos]

La app guarda tus conversaciones, tu actividad y su comprador local en una carpeta `gyblos-desktop`, y, cuando
la configuras, su billetera en una carpeta `gyblos-wallet`, ambas dentro de la carpeta de datos de aplicaciones del sistema:

| Sistema | Carpeta                         |
| ------- | ------------------------------- |
| macOS   | `~/Library/Application Support` |
| Windows | `%APPDATA%`                     |
| Linux   | `~/.config`                     |

Las versiones publicadas también suben recibos firmados sin contenido y observaciones de telemetría;
consulta [Datos y privacidad](/es/reference/data-and-privacy).

Para desinstalarla, borra la app. Las carpetas de datos se quedan hasta que las borres.

<Callout type="warn" title="Borrar gyblos-wallet borra tu billetera">
  Borrar la carpeta `gyblos-wallet` elimina para siempre las llaves de la
  billetera y los fondos que tengan. No se puede deshacer. Antes, haz una copia
  de la billetera desde **Payments**, o conserva la carpeta.
</Callout>
