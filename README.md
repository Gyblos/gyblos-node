# Gyblos Node

Gyblos is an open market for AI inference where agents pay per token in USDC to
independent GPU sellers.

[Website](https://gyblos.tech) · [Docs](https://docs.gyblos.com/en) ·
[Telegram](https://t.me/gyblos) · [X](https://x.com/gyblos)

**Devnet beta.** Use test funds and devnet keys. See the
[known limitations](docs/limitations.md).

## Get started

- [Install the desktop app](https://docs.gyblos.com/en/buyers/desktop-app)
- [Connect your code or agent](https://docs.gyblos.com/en/buyers/use-from-code)
- [Run a seller node](https://docs.gyblos.com/en/sellers/beta-guide)

Release builds upload signed usage receipts without an opt-out. See
[what gets sent](docs/receipts.md#what-leaves-your-machine).
